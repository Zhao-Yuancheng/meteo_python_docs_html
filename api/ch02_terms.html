第 2 章术语：基本数据类型、变量和运算符#

配套 基本数据类型、变量和运算符 正文使用。每个词条 = 一句话定义 + 生活类比 + 代码示例 + 易混淆点。

参见

配套正文：基本数据类型、变量和运算符　·　配套练习：第 2 章配套练习：站点信息与气温数据

变量#

指向某个对象的名字，赋值即"贴标签"。

生活类比 —— 变量不是装数据的盒子，而是贴在盒子上的标签。内存里的对象（盒子）先存在，elevation = 1517.2 只是把 elevation 这张标签贴上去；同一个盒子可以贴多张标签，换标签、贴新标签都不动盒子本身。

station_name = "兰州"    # 给字符串对象贴上 station_name 标签
alias = station_name     # 再贴一张标签：两个名字指向同一对象
print(alias)             # 兰州

易混淆点 —— = 是赋值（贴标签），不是数学上的"等于"，判断相等要用 ==；变量名区分大小写，Temp 与 temp 是两个互不相干的变量。

整型 int#

没有小数部分的整数类型。

生活类比 —— 气象站值班日志里的整件计数：区站号 52889、2024 年共 366 天、14 时观测。这些量天然没有"半个"，就像不会有人报"今天观测了 3.7 次温度"。

station_id = 52889        # 兰州站区站号
year_days = 366           # 闰年天数
print(type(station_id))   # <class 'int'>

易混淆点 —— 不带小数点的数字默认就是 int；只要写了小数点，哪怕数值是整数，类型也会变成 float——1518.0 不是整型。另外 10 / 5 的结果是 2.0（float），除法永远不产生整型；想要整型结果用整除 10 // 5。

浮点型 float#

带小数部分的实数类型，内部用二进制近似存储。

生活类比 —— 观测场里那把带毫米刻度的尺子：气温 12.7 °C、纬度 36.06°N、海拔 1517.2 m，连续物理量都需要小数精度。但尺子有最小刻度，浮点数也有精度极限：它能无限接近、却未必精确等于你写下的十进制数。

lon = 103.83              # 兰州经度
lat = 36.06               # 兰州纬度
temp = 12.7               # 气温
print(type(temp))         # <class 'float'>

print(0.1 + 0.2)          # 0.30000000000000004 —— 精度误差的直观展示

易混淆点 —— 浮点运算存在精度误差，0.1 + 0.2 != 0.3。气温判等不要直接用 ==，用容差：abs(t1 - t2) < 1e-6。有效数字很多不等于精确——float 约 15–17 位有效数字，超出部分是"刻度幻觉"。

字符串 str#

由字符组成的不可变序列，用引号包裹。

生活类比 —— 纸质观测记录本上手写的那一行文字："兰州，晴，西北风"。它的职责是被读取、被展示、被誊抄，但不能拿去和数字相加。

station_name = "兰州气象观测站"
unit = "°C"
info = f"气温单位：{unit}"
print(type(station_name))   # <class 'str'>
print(info)                 # 气温单位：°C
print(station_name[0:2])    # 兰州：字符串可按下标切片

易混淆点 —— 数字一旦加引号就是字符串："25" 是文本，"25" + 5 抛 TypeError；不加引号的 25 才是数字。字符串不可变：s[0] = "x" 会报错。站号 "010" 这类含前导零的编号必须用字符串存，int("010") 会把零丢掉。

布尔值 bool#

只有 True / False 两个值的逻辑类型，比较运算的结果。

生活类比 —— 值班台上的双态指示灯：高温预警要么亮要么灭，没有"半亮"。观测业务里满是这种是非判断：气温是否 ≥35 °C、是否达到暴雨量级。

temp = 28
is_hot = temp > 30          # 判据不成立
print(is_hot)               # False
print(type(is_hot))         # <class 'bool'>

is_heatwave = temp >= 35    # 高温日判据
print(is_heatwave)          # False

易混淆点 —— 只有 True / False 两种写法，首字母大写；写 true / false 会触发 NameError。布尔是整型的子类：True == 1、False == 0；0、0.0、""、[] 等空值都视作假，其余视作真。

可变类型#

创建之后还能原地修改内容的类型（list、dict、set）。

生活类比 —— 一排带编号抽屉的柜子（list）或一柜可更换内容的档案抽屉（dict）：东西放进去之后，随时可以取出来换新的、加一格、删一格，柜子还是原来那个柜子。

temp_list = [12, 15, 18]
temp_list[0] = 10              # 原地修改：换掉 0 号抽屉的内容
temp_list.append(21)           # 原地追加：柜子加长一格
print(temp_list)               # [10, 15, 18, 21]

station = {"temp": 25.6}
station["temp"] = 26.1         # 字典同样可原地更新
print(station)                 # {'temp': 26.1}

易混淆点 —— 列表、字典、集合是可变类型；元组、字符串、数字是不可变类型。可变对象做函数参数时要当心"原地修改"：函数内的 append 会影响到函数外的同一个列表（第 4 章细讲）。

不可变类型#

创建之后内容不可修改的类型（int、float、str、tuple），改动只能通过"造新对象 + 重新贴标签"完成。

生活类比 —— 出厂塑封的仪器标定卡：坐标、传感器编号一旦打印封装，谁都改不了；要"改"只能重新印一张新卡、贴新标签，旧卡作废。

location = (103.83, 36.06)     # 元组：兰州站经纬度
print(location[0])             # 103.83：可以读
# location[0] = 104.0          # TypeError！不可原地修改

s = "Lanzhou"
# s[0] = "l"                   # TypeError！字符串同理
s = "l" + s[1:]                # 正确姿势：生成新字符串再重新赋值
print(s)                       # lanzhou

易混淆点 —— 对不可变对象做"修改"会抛出 TypeError；想改只能重新赋值，生成新对象。不可变是元组能当字典键、能进集合的原因。x = x + 1 对 int 是"造了新对象再贴标签"，而不是原地加一。

索引#

按位置编号存取序列元素的方式，编号从 0 开始。

生活类比 —— 收纳柜的格子编号：气象观测一线给序列编号的习惯是"第 1 个、第 2 个"，Python 却坚持从 0 号格开始数——第 1 个元素住在 0 号格。负数编号则像倒着数：-1 是最后一格。

temp_list = [5, 10, 15, 20]     # 四个时次气温
print(temp_list[0])             # 5    —— 第 1 个
print(temp_list[2])             # 15   —— 第 3 个
print(temp_list[-1])            # 20   —— 倒数第 1 个

易混淆点 —— Python 索引从 0 开始，不是 1；"第 3 个元素"的下标是 2。下标越界抛 IndexError：长度为 4 的列表没有下标 4。负索引从 -1 开始（-1 是最后一个），不存在 -0。

切片#

按 [起:止:步长] 一次截取序列中连续（或等间隔）的一段，返回新对象。

生活类比 —— 从整卷记录纸上按时间剪一段："把 1 号到 7 号的观测剪下来"——从 1 号开始剪，剪到 8 号之前停下（8 号那张留给下一段）。剪下来的是复印件，不是原件本身。

temp_list = [2, 6, 9, 13, 17, 21]
print(temp_list[1:4])     # [6, 9, 13]       下标 1、2、3，不含 4
print(temp_list[:3])      # [2, 6, 9]        省略起点：从头开始
print(temp_list[3:])      # [13, 17, 21]     省略终点：到末尾
print(temp_list[::2])     # [2, 9, 17]       步长 2：隔一个取一个
print(temp_list[::-1])    # [21, 17, 13, 9, 6, 2]  负步长：倒序

易混淆点 —— 规则是左闭右开：[1:4] 包含下标 1、2、3，不含 4——"到谁为止"的那一位永远取不到，这样 a[:n] 恰好是前 n 个。切片不会越界报错：temp_list[1:100] 安静地返回到末尾为止。对列表切片得到的是新列表，改新列表不影响原列表。

空值#

None 表示"这里暂时没有值"，是 NoneType 类型的唯一成员。

生活类比 —— 值班日志上画着横线的空栏：不是填了 0（0 意味着"观测到了零这个数"），而是这一栏根本没写——仪器故障、数据缺测。None 就是那个"未填"状态。

precip = None                 # 降水量缺测
print(precip is None)         # True：判断空值一律用 is

precip = 0.0                  # 修复后补录：观测到没有降水
print(precip is None)         # False
print(type(None))             # <class 'NoneType'>

易混淆点 —— None 不等于 0、""、[]：后三者是"值为空的数据"，None 是"压根没有值"。判断是否为 None 用 is None / is not None，不用 ==。没有写 return 的函数默认返回 None——初学者常被 result = my_func() 结果是 None 迷惑。
