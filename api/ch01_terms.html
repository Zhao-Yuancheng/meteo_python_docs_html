第 1 章术语：Python 简介及安装环境#

配套 Python 与 Conda 简介 正文使用。每个词条 = 一句话定义 + 生活类比 + 代码示例 + 易混淆点。本章术语围绕"装环境、跑代码"展开。

参见

配套正文：Python 与 Conda 简介　·　配套练习：第 1 章练习：Python 简介及安装环境

解释器#

逐行把 Python 代码翻译成机器可执行的指令，并即时运行、返回结果的程序。

生活类比 —— 点菜：你（程序员）报菜名（写代码），餐厅后厨（解释器）先核对菜单上有没有这道菜（语法检查），能做的立刻下锅（编译成字节码），做好端上来（标准输出）；菜不在菜单或口音含糊（语法错误），它会告诉你"做不了"（错误输出）。

x = 6 + 6
print(x)            # 12：解释器逐行执行后反馈结果

易混淆点 —— 解释器 ≠ 编译器：传统上"解释器逐行翻译、编译器整体翻译再执行"，但现代 Python 两者兼具——先整体编译成字节码，再逐条解释执行。解释器 ≠ 编辑器：VS Code 只是"写字台"，真算的是解释器。

环境#

支撑软件运行或开发所需的全部软件配置与资源总和，包括 Python 版本、第三方库、系统依赖与配置项。

生活类比 —— 代码是"需要加工的菜"，环境就是厨房：开发环境是你家厨房（方便即可）、测试环境是工厂车间（标准严格）、生产环境是餐厅后厨（稳定且规范）。同一菜谱在不同厨房做出来味道可能不同。

python --version     # 查看当前环境 Python 版本
pip list             # 查看已装第三方库

易混淆点 —— 环境差异（换机器才报错）≠ 代码出错（原地反复报错）；环境 ≠ 硬件：硬件是"毛坯房"，环境是"装修好的房子"，用途由环境决定。

PATH#

操作系统查找可执行程序的搜索路径列表。敲 conda、python 时按 PATH 里的文件夹逐个寻找。

生活类比 —— 系统配的"寻人导航"：你说"找 conda 这个人"，系统按 PATH 名单上的地址挨个敲门，敲到哪家有就叫谁出来。conda 没登记进名单，系统就喊"查无此人"。

echo %PATH%        # Windows 查看搜索路径
echo $PATH         # macOS / Linux
where conda        # Windows 查看 conda 被装到哪个路径

易混淆点 —— "conda 不是内部或外部命令"就是典型的 PATH 没配好（安装时没勾"Add to PATH"或没重开终端）。PATH ≠ 安装目录：它只是"导航名单"，不代表软件装在哪。

包管理器#

自动下载、安装、升级、卸载并管理第三方库及其依赖的工具。气象生态里 conda 与 pip 都是。

生活类比 —— 请客备菜：主菜（Cartopy）还依赖调味料（底层 C 库）。包管理器是"全能采购员+总厨"，你说"做 Cartopy 这道菜"，它把主配料和调味料一起买齐摆好。

conda install cartopy          # conda：连二进制依赖一起装（气象库首选）
pip install requests           # pip：轻量辅助工具

易混淆点 —— conda 管解释器+底层依赖（气象大库必须用它），pip 只管纯 Python 包；装到哪个环境取决于当前激活的是哪个环境，装错环境是新手常踩的坑。

IDE#

把编辑、运行、调试、终端、版本管理等功能集成在一起的图形化开发工具。本课程主角是 VS Code。

生活类比 —— 现代化实验室操作台：记事本写代码像拿烧杯手工调配，IDE 把烧杯、加热台、记录本、校准一起摆上台面——能边写边运行、出错停在"哪一步出岔子"（断点调试）。

code weather_project/          # 终端用 VS Code 打开项目文件夹

易混淆点 —— IDE ≠ 解释器（VS Code 只是编辑器，跑代码靠解释器）；IDE ≠ 环境（须把解释器绑定到 IDE，本课程是 met_p312，两者就位才能跑代码）。

脚本#

以文本形式保存的一系列 Python 代码，通常放 .py 文件里，交给解释器逐行执行。

生活类比 —— 一张写好的菜谱：把"洗菜、切菜、下锅、调味"按顺序写成文字保存，下次照着念一遍就能重复。main.py 就是本项目第一张"菜谱"。

python main.py                 # 在终端运行一个脚本文件

易混淆点 —— 脚本（自己从头跑到尾）≠ 模块（被 import 供别人调用），同为 .py 文件，区别在第 4 章细讲；脚本 ≠ 交互式输入（REPL 逐行敲不是保存成文件的脚本）。
