气象数据计算 NumPy#

第 6 节 · 模块二 气象数据处理 贯穿项目第 6 步：用 NumPy 数组存储多站气温矩阵，做向量化计算与标准化。

本章目标：掌握 NumPy 数组基础，能够处理气象站点、简单格点数据。NumPy 是 Python 做科学计算最基础的库，气象里面的温度场、气压场、站点观测记录，底层几乎都依靠 ndarray（多维数组）存储与计算。

> 为什么功夫要在 NumPy 上？给你一张「西北 8 站 × 30 天的气温表」，用 Python 普通列表去求每个站的平均气温，你要手写三层 for 循环；用 NumPy，一行 mean(axis=0) 搞定——而且它把数据连续存放在内存、用 C 语言在底层做运算，快出几十上百倍。这就是气象数据处理的第一块敲门砖。

# 使用 NumPy 第一步，导入库（习惯起别名 np）
import numpy as np

6.1 ndarray 数组的创建#

ndarray 是 NumPy 的核心对象，中文叫多维数组。

警告

重要特点：一个数组里所有元素必须是同一个数据类型，要么全部是整数，要么全部是浮点数。它不像 Python 普通列表那样可以混杂数字、字符串。这在气象上反而成了优点——同一张气温表里不可能「温度旁边还站着一个苹果」。

6.1.1 从 Python 列表生成数组#

np.array() 可以把我们已经熟悉的 Python 列表转成 ndarray 数组。

# 一维数组：模拟沿河西走廊某条剖面上 5 个站点的瞬时气温（℃）
temp_list = [15.2, 16.1, 14.8, 17.3, 15.9]
arr1 = np.array(temp_list)
print(arr1)
# 输出：array([15.2, 16.1, 14.8, 17.3, 15.9])

# 二维数组：行代表不同时刻（天），列代表不同站点
# 3 天 × 3 站的气温矩阵
arr2 = np.array([
    [12.0, 13.0, 14.0],   # 第 1 天：兰州、张掖、武威
    [14.5, 15.2, 13.8],   # 第 2 天
    [13.0, 12.4, 15.1],   # 第 3 天
])
print(arr2)

查看数组基础属性（初学者务必记住这四个「身份证号」）：

print(arr2.ndim)    # ndim  维度：二维数组返回 2（行、列两个轴）
print(arr2.shape)   # shape 形状：(行数, 列数)，气象里经常看 shape 判断数据对不对
print(arr2.dtype)   # dtype 数组内元素的数据类型
print(arr2.size)    # size  数组总元素个数
# 输出：2  (3, 3)  float64  9

气象场景：拿到一张格点温度场，先 print(shape)，看到 (181, 360)，你就知道这是一张 1°×1° 的全球网格（纬度 0–180、经度 0–360），而不是 360×181——shape 的顺序乱了，后面的计算全盘皆输。

6.1.2 快速生成常用数组#

实际处理气象数据，很多时候不需要手动写列表，直接调用函数生成。

1. ``np.zeros(shape)``：生成全部为 0 的数组，常用于初始化存放结果的「空容器」。

arr_zero = np.zeros((3, 4))   # 3 行 4 列，全部填 0

2. ``np.ones(shape)``：生成全部为 1 的数组。

arr_one = np.ones((2, 5))

3. ``np.arange(start, stop, step)``：按步长生成一维数组，左闭右开，不包含 stop。

arr_ar = np.arange(0, 10, 2)   # [0 2 4 6 8]

4. ``np.linspace(start, stop, num)``：在起止区间，生成指定个数、均匀间隔的数据，包含 stop。

气象常用：生成经度、纬度序列。把 0–360° 经度均匀切成 19 个格点：

lon = np.linspace(0, 360, 19)
print(lon)
# 输出：[  0.  20.  40. ... 340. 360.]

备注

  • arange 控制步长（间隔多大）；linspace 控制总点数（切多少份）。

  • 传入形状时一定要写括号：np.zeros((3, 4))，而不是 np.zeros(3, 4)。

本动画把 ndarray 的「变身术」一口气演给你看：① reshape 重排形状——把一维列表摆成多维矩阵；② transpose/.T 转置——行列互换；③ ravel 展平——多维压回一维。形状怎么变，底层数据始终是同一份，就像一张可以折叠、翻面、摊平的气温网格。点击播放，配合后面 6.2 的索引与切片逐步消化。

6.2 数组索引与切片#

索引：取出数组某一个元素；切片：取出数组的一整块子数组。

二维数组书写格式：数组[行, 列]。

本动画把 NumPy 的索引与切片讲透：① 下标从 0 开始——你要找的「第 3 个站」写成 [2]；② 用 [行, 列] 精确定位单个元素；③ 切片 [start:end:step] 左闭右开，能整块取出子数组；④ 切片返回的是原数组的视图，改名为新变量后改动仍会连带原数组。点击播放，反复拖看高亮的那一格／那一片最直观。

6.2.1 基础索引#

arr = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
])

print(arr[0, 1])   # 第 0 行、第 1 列，值 20
print(arr[2, 0])   # 第 2 行、第 0 列，值 70

警告

计算机下标从 0 开始：第一行是 0 号，不是 1 号。气象小哥的「第 81 个站」在代码里是下标 80。

6.2.2 切片语法#

切片格式：start:end:step，左闭右开，end 位置不取。

start 省略默认从 0 开始；end 省略默认到末尾；step 省略默认步长为 1。

# 取前两行、全部列
s1 = arr[0:2, :]

# 全部行、第 1 列到末尾
s2 = arr[:, 1:]

# 隔行取，步长 2
s3 = arr[::2, :]

警告

初学者高频坑：NumPy 切片返回的是原数组的视图（view），不是独立拷贝。修改切片得到的变量，原始数组的数据也会跟着改变！这就好比你把复印纸批改后，发现原稿也一起被改了。

sub = arr[0:2, :].copy()

6.3 向量化运算#

向量化运算：数组直接参与加减乘除，不需要写 for 循环，运算作用到数组的每一个元素。

这是 NumPy 最高频的功能，处理气象格点数据几乎全部依赖它。

数组和标量运算：数组每一个元素统一和数字计算。比如气象中开尔文温标转摄氏度：T_c = T_k − 273.15。

# 开尔文温度数组（三个格点的温度）
T_k = np.array([285.0, 288.2, 290.5])
T_c = T_k - 273.15
print(T_c)
# 输出：[11.85 15.05 17.35]

数组与数组逐元素运算：两个形状一样的数组，+ - * / ** 全部是对应位置元素两两计算，不是矩阵乘法。

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
c = a + b      # [11 22 33]
d = a * b      # [10 40 90]

备注

重要区分：

  • *：逐元素相乘；

  • @ / np.dot()：矩阵乘法。初学者不要搞混！

对比：如果用普通 Python 列表，实现上面的求和必须写循环；NumPy 向量化底层用 C 语言实现，速度会快几十上百倍。这就是「一块算一整片」与「一个格子一个格子用手抠」的天壤之别。

6.4 广播机制#

广播（broadcasting）：当两个数组形状不完全一样时，NumPy 自动把数组进行虚拟扩展，完成运算，但不会复制真实数据，节省内存。

气象场景例子：二维温度场（西北 8 站 × 5 天），给每一天加一个相同的订正偏差（比如每个站点对某天的仪器误差校正是 0.5℃）时，我们就可以用小的一维数组和大的二维数组直接相加。

广播三条规则（初学者熟读）：

  1. 从最右侧维度开始对齐两个数组的维度；

  2. 对应维度大小相等，或者其中一个维度等于 1，就可以广播；

  3. 如果不满足上面条件，直接报错，不能运算。

示例： a 形状 (8, 5)，b 形状 (5,)

# 西北 8 站 × 5 天的气温场
a = np.ones((8, 5))

# 逐天订正偏差向量（5 个元素，对应 5 天）
b = np.array([0.5, 0.2, -0.3, 0.1, 0.0])

res = a + b
print(res.shape)
# 输出：(8, 5)

b 这个一维数组会自动虚拟扩展为 (8, 5)，再和 a 相加，内存并没有真正生成一份 (8, 5) 的数组。

警告

易错提醒：维度对齐从尾巴往前，不是从开头。把 a 看作一排排站好的士兵，b 那个小向量就是「号令」，最后面的号令对齐到最右侧那一列，然后往前广播。

6.5 数组常用统计函数#

统计函数用来求数组均值、最大值、总和等。关键参数 axis，控制沿着哪一个轴做运算。

常用统计函数#

函数

作用

np.mean()

求平均值

np.sum()

求和

np.max()

最大值

np.min()

最小值

np.std()

标准差

用「3 站 × 5 天」的气温矩阵来理解 axis：

# 行 = 3 天，列 = 5 个站点
data = np.array([
    [12, 14, 16, 13, 15],
    [18, 20, 22, 19, 21],
    [15, 17, 19, 16, 18]
])

# 不写 axis：全部元素当成一个整体计算
print(data.mean())
# 输出：所有 15 个数的整体平均

# axis=0：沿着行方向运算，压缩行，得到每一列的结果
print(data.mean(axis=0))
# 每个值 = 某个站点所有天的平均

# axis=1：沿着列方向运算，压缩列，得到每一行的结果
print(data.mean(axis=1))
# 每个值 = 某一天所有站点的平均

备注

记忆口诀：

  • axis=0 → 消掉行，输出每一列；

  • axis=1 → 消掉列，输出每一行。

用坐标系想：把数组铺在纸上，axis=0 是竖直方向（从上往下消行），axis=1 是水平方向（从左往右消列）。

气象格点求纬向平均、经向平均，就是修改 axis 参数——对一张 (纬度, 经度) 的温度场，mean(axis=0) 得到沿经度的平均（每个纬带的平均值），mean(axis=1) 得到沿纬度的平均（每个经圈的平均值）。

提升拓展部分（选学，难度更高）#

6.6 布尔索引（掩码 mask）#

布尔索引使用布尔数组筛选数据，气象超级常用：筛选大于某阈值温度、过滤缺测值等。

布尔索引返回数组副本，修改结果不会改动原数组。

temp = np.array([22, 25, 28, 31, 33])

# 生成布尔掩码，满足条件为 True，不满足为 False
mask = temp > 28
print(mask)
# 输出：[False False False  True  True]

result = temp[mask]
print(result)
# 输出：[31 33]

只有 mask 为 True 的位置，对应元素被保留。

气象示例：把观测值中明显异常的高温（比如超过 45℃ 的假数据）过滤掉：

temp = np.array([25.0, 30.2, 47.8, 28.1, 32.0])
clean = temp[temp <= 45.0]      # 只保留 ≤45℃ 的正常值
print(clean)
# 输出：[25.0 30.2 28.1 32.0]

6.7 花式索引#

通过传入整数列表/数组，选取不连续的下标，可以自由挑取任意位置的元素，同样返回副本。

arr = np.array([10, 20, 30, 40, 50])
idx = [0, 2, 4]        # 需要取出元素的下标
res = arr[idx]
print(res)
# 输出：[10 30 50]

和切片区别：切片只能取连续片段；花式索引可以「跳着取」。比如从一长串观测里只挑出每天 0 点、6 点、12 点、18 点作 4 时次采样。

6.8 数组拼接 np.concatenate#

把多个数组拼在一起，axis 决定拼接方向。

a = np.zeros((2, 2))
b = np.ones((2, 2))

# axis=0：上下堆叠（行拼接），行数增加
res_vert = np.concatenate([a, b], axis=0)
print(res_vert.shape)   # (4, 2)

# axis=1：左右拼接，列数增加
res_hori = np.concatenate([a, b], axis=1)
print(res_hori.shape)   # (2, 4)

警告

拼接要保证非拼接维度的大小一致，不然会报错。这就好比把两段铁轨首尾相连，接口处的尺寸必须严丝合缝。

6.9 结构化数组#

普通 ndarray 全部元素同一类型；结构化数组可以定义多个不同类型字段，模拟表格，适合存储站点观测：站点编号（整数）、温度（浮点数）、气压（浮点数）。

# 定义字段：字段名 + 数据类型
dtype_obs = [("sid", "i4"), ("temp", "f8"), ("press", "f8")]

obs = np.array([
    (54511, 23.2, 1002.5),   # 西北某站：温度 23.2℃，海平面气压 1002.5 hPa
    (54512, 21.8, 1004.1),
    (54718, 19.6, 1007.3),
], dtype=dtype_obs)

# 使用字段名字取出整列数据
print(obs["temp"])       # [23.2 21.8 19.6]
print(obs["sid"])        # [54511 54512 54718]

小提示：实际气象项目更多用 pandas 表格来做这类事，结构化数组了解一下即可。

初学者本章小结#

  1. ndarray 是同类型多维数组，用 shape 看形状、dtype 看类型；

  2. 切片返回视图，修改会影响原数组，需要独立数据用 .copy()；

  3. 向量化运算代替循环，效率高；

  4. axis=0 压缩行、axis=1 压缩列（消行输出列、消列输出行）；

  5. 广播从最右侧维度对齐，维度相等或其一为 1 才能运算；

  6. 布尔索引 mask 用于气象筛选与过滤异常数据。

6.10 最佳实践：多站气温矩阵与安全统计#

本节把上面的知识点全部串成一条能给真实气象项目用的生产线：多站气温矩阵计算（逐站均值 / 逐日极值）、标准化（Z-score）处理、NaN 安全运算，并逐点给出 ✅ 最佳实践与 ⚠️ 风险点。

在正式看代码前，先立好一张矩阵地图：

  • 行 = 时间（天），列 = 站点。以「西北 8 站 × 5 天」为例，shape 就是 (5, 8)。

  • 想要求每个站的平均气温 → 沿站点这一维压缩 → axis=0（列方向）；

  • 想要求每天的区域极值 → 沿时间这一维压缩 → axis=1（行方向）。

axis 写反，是这类任务最高频的开关错误，务必对照这张地图来检查。

6.10.1 完整标准化工作流程#

  1. 导入 numpy/pandas，读取（或构造）多站气温矩阵数据；

  2. 缺测预处理：气象缺测标记转换为 NaN，校验矩阵维度（时间行 × 站点列）；

  3. 逐站统计：按站点列计算各站均值、标准差、有效样本数；

  4. 逐日统计：按时间行计算逐日区域极大、极小值；

  5. 标准化处理（Z-score）：逐站做标准化，规避 NaN 破坏计算；

  6. NaN 安全原则：运算全程保留缺测标记，不强行填充无效值；

  7. 输出统计结果与标准化矩阵，保存文件。

6.10.2 构造 / 读取多站气温矩阵#

✅ 最佳实践

  1. 多站矩阵一般约定：行 = 时间，列 = 各个观测站点；

  2. 将气象缺测标识 9999、-999.0 读取时转为 np.nan；

  3. 读取完成后打印行列维度，确认「时间 × 站点」矩阵形状正确。

为了让本讲可以直接复现，下面先用固定随机种子构造一张「西北 8 站 × 10 天」的气温矩阵（含故意埋入的 9999 缺测）。真实业务里，这一步换成 pd.read_csv(...) 即可，两种写法都列出：

import numpy as np
import pandas as pd

# —— 方案 A：直接用 np.random 构造内存中可复现的样例数据 ——
rng = np.random.default_rng(20260817)
sites = ["兰州", "张掖", "武威", "敦煌", "酒泉", "金昌", "嘉峪关", "临夏"]

# 8 站 × 10 天气温矩阵（℃），先填 0 再叠加各站均值 + 随机扰动
raw = np.zeros((10, len(sites)))
for j, base in enumerate([16.2, 13.5, 14.0, 18.6, 12.8, 15.4, 13.9, 14.6]):
    raw[:, j] = base + rng.normal(0, 1.5, 10)
raw[3, 2] = 9999.0    # 埋一个异常缺测，测试缺测识别
raw[8, 5] = -999.0    # 再埋一个

df = pd.DataFrame(raw, columns=sites,
                  index=pd.to_datetime("2026-07-01") + pd.TimedeltaIndex(range(10), unit="D"))
df.index.name = "date"

# —— 方案 B：真实业务读取 CSV（缺测标识转 NaN）——
# df = pd.read_csv(
#     "multi_station_temp.csv",
#     parse_dates=["date"],
#     encoding="utf-8-sig",
#     na_values=["9999", "-999.0"],
#     index_col="date",
# )

# 缺测标识 9999 / -999.0 → NaN
df = df.replace([9999.0, -999.0], np.nan)

# 核查矩阵结构：行 = 时间，列 = 站点
print("矩阵形状(时间, 站点):", df.shape)
print(df.head())

⚠️ 风险点

  • 行列搞反：把站点当行、时间当列，全部统计结果错乱；

  • 缺测 9999 未转为 NaN：它会被当成真实气温参与均值、标准化计算，污染整个统计。

6.10.3 逐站均值 / 标准差统计（按列）#

✅ 最佳实践

pandas 的 .mean()、.std() 默认 skipna=True，自动跳过 NaN，非常适合气象多站数据。得到每个站点一段时间内的平均气温与气温标准差。

# 逐站：各站均值、各站标准差、有效样本数
station_mean = df.mean(axis=0)      # axis=0 → 按列 = 每个站
station_std  = df.std(axis=0)       # ddof 默认 1（样本标准差）
valid_count  = df.count(axis=0)     # 每个站的有效观测数

print("各站点平均气温：")
print(station_mean)
print("各站点有效观测数：")
print(valid_count)

⚠️ 风险点

  • axis=0 按列（站点）；如果写成 axis=1 会按时间行，逻辑彻底颠倒；

  • 某站点如果大量缺测，均值依旧会输出一个数字，业务上必须结合 valid_count 评估该均值可信度。

6.10.4 逐日区域极值统计（按行）#

✅ 最佳实践

axis=1 跨站点按行运算：每一天，对全部站点求当日区域最高、区域最低气温。

# 逐日区域极值：每一天全部站点的最大、最小气温
df["day_area_max"] = df.max(axis=1)
df["day_area_min"] = df.min(axis=1)

print(df[["day_area_max", "day_area_min"]].head())

⚠️ 风险点

  • 若某一天所有站点均为 NaN，max/min 返回 NaN，代表该日无有效观测，不可强行填充；

  • axis 参数写反，会变成在每天内计算某个站点的极值序列，而不是逐日区域极值。

6.10.5 逐站 Z-score 标准化，NaN 安全运算【核心】#

备注

Z-score 公式：z = (x − μ) / σ，其中 μ 是站点均值、σ 是站点标准差。关键是：按站点分别标准化，不能全局整体标准化。

✅ 最佳实践

逐列（按站点）做标准化；存在 NaN 的位置，结果依旧保留 NaN，不污染矩阵。NaN 是「占位符」不是「错误」，让它原样传下去即可。

备注

不能直接拿整个 numpy 数组做整体运算，那样会把全局的值一起算进去；pandas 逐列运算天然按列、天然 skipna，是安全的选择。

# 逐站 Z-score 标准化（σ 用样本标准差，与上方 station_std 一致）
temp_zscore = (df - station_mean) / station_std

print("标准化矩阵形状：", temp_zscore.shape)
print(temp_zscore.head())

⚠️ 风险点

  1. 全局标准化（错误）：全部数据用同一个总均值、总标准差，抹杀了站点间气候本底差异，气象多站分析中严禁这样做；

  2. 某站点标准差接近 0（例如事件期内气温几乎不变），会出现除零/溢出：z 被放大到 ±∞，业务代码应增加判断过滤；

  3. 手动把 NaN 填充为 0，会彻底破坏标准化结果。

若站点标准差极小，可做保护：

eps = 1e-8
safe_std = station_std.replace(0, np.nan).fillna(eps)   # 或直接判断过滤
temp_zscore = (df - station_mean) / safe_std

6.10.6 NaN 安全运算最佳实践#

✅ 最佳实践

  1. 气象数据：缺测优先保留 NaN，不随意填充 0、均值；

  2. numpy 函数优先使用 np.nanmean、np.nanstd 系列，自动跳过 NaN；普通 np.mean 遇到 NaN 直接输出 NaN；

  3. 统计完成输出每个站点的有效观测计数，用于判断统计结果可靠性。

# 示例：用 numpy 的 NaN 安全函数求整体逐站均值（对比）
print("np.nanmean 逐列（站点）均值：", np.nanmean(df.values, axis=0))

⚠️ 风险点

直接使用 df.fillna(0)，会把缺测当成 0 度气温，所有统计、标准化全部失效。缺测信息一旦被「填平」就再也找不回来，务必先想清楚缺测怎么处理再动手填充。

6.10.7 结果保存输出#

✅ 最佳实践

保存时保持矩阵行列结构不变，用 utf-8-sig 编码；NaN 在 csv 中保留为空单元格。

# 保存站点统计（含中文站点名的指标表）
station_stats = pd.DataFrame({
    "站点均值": station_mean,
    "站点标准差": station_std,
    "有效观测数": valid_count,
})
station_stats.to_csv("station_stats.csv", encoding="utf-8-sig")

# 保存标准化矩阵
temp_zscore.to_csv("temp_zscore.csv", encoding="utf-8-sig")

# 保存逐日区域极值结果
df[["day_area_max", "day_area_min"]].to_csv("day_area_extreme.csv", encoding="utf-8-sig")

⚠️ 风险点：不设置编码参数（encoding="utf-8-sig"），中文站点名会乱码。

6.10.8 完整可运行最佳实践总代码#

运行后会在当前目录生成三个 csv 文件：station_stats.csv、temp_zscore.csv、day_area_extreme.csv。

import numpy as np
import pandas as pd

rng = np.random.default_rng(20260817)
sites = ["兰州", "张掖", "武威", "敦煌", "酒泉", "金昌", "嘉峪关", "临夏"]

# 构造并识别缺测，构造 8 站 × 10 天气温矩阵
raw = np.zeros((10, len(sites)))
for j, base in enumerate([16.2, 13.5, 14.0, 18.6, 12.8, 15.4, 13.9, 14.6]):
    raw[:, j] = base + rng.normal(0, 1.5, 10)
raw[3, 2] = 9999.0
raw[8, 5] = -999.0

df = pd.DataFrame(raw, columns=sites,
                  index=pd.to_datetime("2026-07-01") + pd.TimedeltaIndex(range(10), unit="D"))
df.index.name = "date"
df = df.replace([9999.0, -999.0], np.nan)

print("原始矩阵形状(时间, 站点):", df.shape)

# 1) 逐站统计：各站均值、标准差、有效样本数
station_mean = df.mean(axis=0)
station_std  = df.std(axis=0)
valid_count  = df.count(axis=0)
print("\n====逐站统计结果====")
print("站点平均气温:\n", station_mean)
print("站点有效观测数:\n", valid_count)

# 2) 逐日区域极值：每日全部站点的区域最大、最小气温
df["day_area_max"] = df.max(axis=1)
df["day_area_min"] = df.min(axis=1)
print("\n====逐日区域极值示例====")
print(df[["day_area_max", "day_area_min"]].head())

# 3) 逐站 Z-score 标准化（NaN 安全，逐列）
temp_zscore = (df.drop(columns=["day_area_max", "day_area_min"]) - station_mean) / station_std
print("\n标准化矩阵形状：", temp_zscore.shape)

# 4) 文件输出（utf-8-sig，避免中文乱码）
station_stats = pd.DataFrame({
    "站点均值": station_mean,
    "站点标准差": station_std,
    "有效观测数": valid_count,
})
station_stats.to_csv("station_stats.csv", encoding="utf-8-sig")
temp_zscore.to_csv("temp_zscore.csv", encoding="utf-8-sig")
df[["day_area_max", "day_area_min"]].to_csv("day_area_extreme.csv", encoding="utf-8-sig")

6.10.9 核心最佳实践总结#

  1. 矩阵维度分清：行代表时间，列代表站点；axis=0 逐站（列）运算，axis=1 逐日（行）运算，axis 写反是高频错误。

  2. 统计逻辑：均值、Z-score 标准化必须按站点分别计算，禁止对全部站点做全局统一标准化——那样会抹平站点气候本底差异。

  3. NaN 安全原则：气象缺测优先保留 NaN，禁止随意 fillna(0)；使用 skipna=True 系列函数自动跳过缺测；同时统计每个站点有效观测数量，评估统计结果可靠性。

  4. 异常保护：站点标准差趋近 0 时会发生除零/溢出，业务代码应增加判断或小量 eps 保护。

  5. 输出编码：读写 csv 统一 utf-8-sig，避免站点中文名乱码。随机数据务必固定 seed，保证结果可复现。

备注

补充：NumPy 的视图 vs 复制。切片返回视图（改切片会同时改原数组，需要独立数据用 .copy()），而布尔索引、花式索引返回副本。多站叠加列（如 df["day_area_max"] = ...）按列对齐时也要留意：永远先 print(shape)、用.copy()，再进入计算，才能避免"改了拷贝、原表也变了"的隐性 bug。
